# Welrent Act (Next.js)

Contracts UI + API for Welrent car and motorcycle rentals. Syncs with
[wr-frontend](https://github.com/welrent/wr-frontend).

See the root [README](../README.md) for architecture, screenshots, and the demo video.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Useful scripts:

- `npm run seed:demo` — sample car/motorcycle contracts
- `npm run seed:agreements` — legal agreement pages
- `npm run migrate` — Turso/schema bootstrap
